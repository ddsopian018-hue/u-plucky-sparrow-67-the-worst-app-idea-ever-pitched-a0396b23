A pure-stdlib Python program that writes one sentence — a pitch for QueueBuddy, the app that hires a stranger to stand in line for you and then charges you $12 an hour to watch them wait on a livestream — to `entry.txt`. The founder means every word: your time is too valuable to queue, but not too valuable to watch someone else queue.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
